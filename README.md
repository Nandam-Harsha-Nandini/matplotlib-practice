# Matplotlib Practice

This repository contains my **Matplotlib practice work** using Python, Pandas, and NumPy.

## 📌 Topics Covered

- Matplotlib basics
- Figure and Axes
- Object-Oriented plotting
- Line charts
- Bar charts
- Histograms
- Scatter plots
- Box plots
- Pie charts
- Subplots
- Rolling averages
- Data visualization using real-world website traffic data
- Misleading vs. honest charts
- Saving plots as PNG images

## 📊 Dataset

The practice uses a **daily web traffic dataset** containing information such as:

- Date
- Visits
- Signups
- Page load time
- Error count
- Deployment information

## 📝 Practice Tasks

1. Plot signups over time using a line chart.
2. Create a histogram of error counts.
3. Compare monthly website visits using a bar chart.
4. Create a scatter plot of visits vs. signups and a box plot of page load time.
5. Use a 7-day rolling average and identify the day with the highest errors.
6. Understand the difference between misleading and honest charts.
7. Save a visualization as a high-quality 300-DPI PNG image.

Through this practice, I learned how to **analyze data and represent it visually** using different types of charts. I also practiced customizing plots, comparing data, identifying trends, and creating clear and meaningful visualizations.
